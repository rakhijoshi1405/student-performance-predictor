# 🎓 Student Performance Predictor

An ML-based web app that predicts a student's final grade (G3) using Linear Regression.

## Features
- Predicts final score (out of 20) based on 5 key inputs
- Shows Pass/Fail result with percentage
- Displays improvement suggestions
- Includes pass/fail threshold and reference tables

## Tech Stack
- Python 3.14
- Streamlit (UI)
- Scikit-learn (Linear Regression)
- Pandas, NumPy, Joblib

## Input Features
- Studytime (weekly)
- Failures (past)
- Absences
- G1 (First Test Score)
- G2 (Second Test Score)
